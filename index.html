Thermal Printer Test

A small utility to test raw ESC/POS printing.

What to print

This app wraps the text in basic ESC/POS commands.

The image is scaled to the paper width and printed in black and white. Use K57 for 58 mm paper and K80 for 80 mm. If a printer prints nothing or garbage, try the other image command.

1. Network printer (TCP/IP)

2. USB printer (direct USB device)

Detects USB devices by VID/PID and sends raw data to a bulk OUT endpoint without selecting an installed printer queue.

Windows note: if the printer's normal driver owns the USB interface, direct access may fail until a compatible WinUSB/libusb driver is installed. Changing the driver can disable normal queue printing. macOS typically does not need a separate driver for libusb access, but device compatibility varies.

3. USB printer (system printer queue)

The printer must be installed in Windows or added in macOS Printers & Scanners. On macOS, raw printing depends on the queue/driver supporting it.

4. Bluetooth Classic (SPP / serial)

Pair a Classic Bluetooth SPP printer with the OS first. Windows usually exposes a COM port; macOS may expose a /dev/tty.* device. This is not BLE.

5. Bluetooth Low Energy (BLE)

Scan and select a nearby BLE device. The app checks several common printer service UUIDs automatically. Some printers use vendor-specific UUIDs that are not discoverable without the correct UUID.
